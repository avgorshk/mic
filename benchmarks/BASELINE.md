# Benchmark baseline

The machine's performance snapshot BEFORE any microarchitecture work.
Generated by `python benchmarks/run_bench.py` — the suite compiles each
MICC program with the current toolchain, runs it on the simulator, and
verifies the checksum result. Cycle counts are logical microcode cycles
(deterministic — no host timing).

Date: 2026-10-24. Simulator: x64 Debug build at the commit introducing
this file. All 11 results verified, coverage 21/21 opcodes.

How to use it: after any microarchitecture change, rebuild micsim, rerun
the suite, and diff against this file. The programs themselves must stay
unchanged (that is the point — only the machine gets faster).

Note: these numbers predate the dispatch-timing model fix (JMPC now uses
the pre-edge MBR; WIDE became 2 cycles). Current numbers are tracked in
the README's micro-architecture versions table.
